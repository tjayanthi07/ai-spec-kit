## Terms

- **Authentication:** The process of verifying a user's identity
- **Authorization:** The process of determining what a user can access
- **Session:** A period of time during which a user is logged in
- **JWT (JSON Web Token):** A compact, URL-safe means of representing claims to be transferred between two parties
- **bcrypt:** A password hashing function designed to be slow and computationally expensive
- **Rate Limiting:** A technique to control the number of requests a user can make in a given time period
- **CSRF (Cross-Site Request Forgery):** An attack that tricks a user into performing unwanted actions
- **XSS (Cross-Site Scripting):** An attack that injects malicious scripts into web pages
- **Password Reset:** The process of setting a new password when the old one is forgotten
- **Multi-Factor Authentication (MFA):** An authentication method requiring two or more verification factors
